# V15 — фикс записи через YCLIENTS times

Исправлены только найденные блокеры записи:

1. Backend `/yclients/dates` больше не зависит слепо от пустого ответа YCLIENTS dates.
   Если `/book_dates` вернул пусто, backend проверяет ближайшие дни через `/book_times` и возвращает даты, где реально есть окна.

2. Flutter экран записи больше не падает в состояние «окон нет» только из-за пустого `/dates`.
   Экран показывает специалиста, дату, время и проверяет `/yclients/times` для выбранной пары услуга+специалист+дата.

3. Предстоящие записи теперь берутся из `YCLIENTS + local cache`, чтобы созданная через приложение запись не исчезала, если YCLIENTS `/records`/`/visits` недоступны по правам.

4. Кнопки «Я опаздываю» и «Отменить запись» отображаются у предстоящей записи в приложении. Backend всё равно соблюдает серверную логику отмены и вернёт ошибку, если YCLIENTS/правила отмены не разрешают отмену.

5. Возвращён обязательный Flutter fallback-файл `mobile_flutter/lib/src/data/demo_content.dart` и исправлен импорт `AppColors` в чате.

Проверки в пакете:

- Backend `npm run build` — OK.
- Backend `npm run lint` — OK.
- Текстовые файлы записаны UTF-8 без BOM.

Важно: live-создание записи, отмена и чтение записей зависят от прав/лицензии YCLIENTS. Уже доказано, что `services`, `staff`, `times` работают; проблема `/records`/`visits` остаётся на стороне доступа YCLIENTS.
