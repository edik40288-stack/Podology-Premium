# Админ-панель контента PODOLOG KUTSYTOI

Админ-панель работает через отдельного Telegram-бота настроек. Этот бот не принимает клиентские сообщения. Клиентские чаты идут через отдельного чат-бота и Telegram-группу с темами.

## Главное меню админ-бота

- 🏠 Главный экран
- 🟩 Блок эксперта / адрес
- 🏥 О центре
- 📜 Сертификаты
- 🛋 Интерьер
- 🌐 360° обзор
- 🦶 Наши работы
- 💅 Услуги
- 👩‍⚕️ Специалисты
- 👤 Профиль
- 👀 Посмотреть что сейчас
- ❔ Помощь

## Что можно менять

### 🏠 Главный экран
Можно менять приветствие, заголовок, описание, цвет фона и фото фона.

Приветствие поддерживает переменную `{имя}`. Например:

```text
Здравствуйте, {имя}
```

### 🟩 Блок эксперта / адрес
Можно менять заголовок, подзаголовок, описание, адрес, ссылку на карту, текст кнопки, цвет и фото фона.

### 🏥 О центре
Можно добавлять фото-блоки и текстовые блоки. Формат подписи к фото:

```text
Название | Описание
```

### 📜 Сертификаты
Можно добавлять сертификат фото + название + описание, менять отдельные поля, удалять элемент.

### 🛋 Интерьер
Можно добавлять фото интерьера. Подпись:

```text
Название | Описание
```

### 🌐 360° обзор
Добавляется ссылкой:

```text
Название | Ссылка | Описание
```

В приложении это показывается отдельной карточкой “360° обзор”.

### 🦶 Наши работы
Можно добавлять фото работы и текст под фото.

```text
Название | Описание
```

### 💅 Услуги
Услуга добавляется строкой:

```text
Значок | Название | Описание | Цена | Длительность
```

Пример:

```text
🦶 | Профессиональный педикюр | Комплексная обработка стоп и ногтей | от 4500 ₽ | 90 мин
```

В приложении услуги показываются горизонтальной лентой.

### 👩‍⚕️ Специалисты
Специалист добавляется текстом или фото с подписью:

```text
Имя | Должность | Стаж | Описание
```

### 👤 Профиль
Можно менять названия и описания разделов профиля. Разделы профиля в приложении кликабельные.

## Где хранится контент

Файл локального MVP:

```text
backend/content/home.json
```

Для сервера лучше вынести это в PostgreSQL и S3/R2-хранилище, но структура уже готова к переносу.
