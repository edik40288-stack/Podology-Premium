# Заметки для модерации App Store и Google Play

## 1. Назначение приложения

«PODOLOG KUTSYTOI» — приложение для записи в центр эстетического и подологического ухода, просмотра информации о центре, специалистах, услугах, сертификатах, работах и общения с администратором через чат.

## 2. Оплата

Приложение не принимает оплату, предоплату, подписки, донаты и не использует встроенные покупки.

## 3. Аккаунт

Аккаунт используется для записи, профиля, истории обращений и чата. В приложении есть удаление аккаунта.

## 4. Данные

Приложение собирает:

- имя и фамилию;
- номер телефона;
- записи на приём;
- сообщения в чате;
- фото/видео, если пользователь сам отправляет их;
- технические данные для работы приложения;
- push token для уведомлений;
- данные о согласиях на маркетинговые сообщения, если пользователь дал согласие.

## 5. Удаление аккаунта

Удаление аккаунта доступно в приложении в профиле. После удаления аккаунта данные удаляются из активных систем приложения. В резервных копиях и технических журналах данные могут сохраняться до 6 месяцев.

## 6. Фото/видео

Фото/видео используются только для связи пользователя с центром. Они не публикуются без отдельного согласия.

## 7. Медицинская лицензия

На текущем этапе медицинской лицензии нет. Приложение не позиционируется как медицинское, не ставит диагнозы и не оказывает медицинскую помощь.

## 8. Ревью-аккаунт

Перед отправкой на модерацию подготовить тестовый аккаунт:

- телефон: уточнить перед отправкой на модерацию
- код: уточнить перед отправкой на модерацию
- описание для ревью: подготовить после включения production API

## 9. Data Safety / Privacy Labels

Перед отправкой заполнить данные в Google Play Data Safety и Apple App Privacy так, чтобы они совпадали с фактическим поведением приложения и настоящими юридическими документами.


## 10. Несовершеннолетние

Приложение не ограничивается пользователями 18+. Запись несовершеннолетнего клиента возможна через родителя или законного представителя. Приложение не предназначено для самостоятельного использования малолетними пользователями без участия взрослого.

## 11. Маркетинговые сообщения

Маркетинговые сообщения допускаются только при отдельном согласии пользователя. Оплата, предоплата и встроенные покупки отсутствуют.
