# Юридический пакет проекта PODOLOG KUTSYTOI

## Статус

Это рабочий юридический пакет для мобильного приложения и backend-сервиса PODOLOG KUTSYTOI.
Документы подготовлены с учётом текущей логики проекта:

- приложение для записи, информирования и коммуникации с центром;
- оплата и предоплата в приложении отсутствуют;
- медицинской лицензии на текущем этапе нет;
- в приложении есть профиль клиента, телефон, запись, чат, фото/видео, удаление аккаунта и смена номера;
- данные хранятся в backend/БД/медиа-хранилище;
- интеграции: YCLIENTS, Telegram, SMS/код авторизации, server/storage;
- регион работы: РФ.

## Важное ограничение

Сертификаты специалистов можно показывать как подтверждение обучения и квалификации, но нельзя подавать их как медицинскую лицензию. До получения лицензии в публичных текстах следует избегать формулировок: «лечение», «диагностика», «врач», «медицинская помощь», «назначение лечения», «терапия», «медицинская услуга».
