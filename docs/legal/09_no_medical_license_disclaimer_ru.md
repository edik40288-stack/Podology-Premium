# Дисклеймер об отсутствии медицинской лицензии

На дату редакции настоящего документа у центра «PODOLOG KUTSYTOI» отсутствует медицинская лицензия.

## 1. Назначение приложения

Приложение используется для записи, информирования и коммуникации по вопросам эстетического и подологического ухода.

## 2. Не медицинская помощь

Информация, размещённая в приложении, а также ответы через чат:

- не являются медицинской консультацией;
- не являются постановкой диагноза;
- не являются назначением лечения;
- не заменяют обращение к врачу;
- не являются оказанием медицинской помощи.

## 3. Сертификаты

Сертификаты специалистов подтверждают обучение, квалификацию, участие в курсах или повышение профессиональных навыков конкретных специалистов. Сертификаты не являются медицинской лицензией.

## 4. Формулировки для приложения

До получения медицинской лицензии рекомендуется использовать:

- «подологический уход»;
- «эстетический уход»;
- «уход за стопами и ногтями»;
- «профессиональный уход»;
- «запись на процедуру»;
- «специалист по подологии».

Не рекомендуется использовать без юридического основания:

- «лечение»;
- «диагностика»;
- «медицинская помощь»;
- «врач»;
- «терапия»;
- «назначение лечения»;
- «медицинская услуга».
