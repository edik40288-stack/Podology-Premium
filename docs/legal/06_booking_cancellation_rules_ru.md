# Правила записи, переноса и отмены

## 1. Запись

Пользователь может записаться на услугу через мобильное приложение «PODOLOG KUTSYTOI». Для записи пользователь выбирает услугу, специалиста, дату и время из доступных вариантов.

## 2. Подтверждение

Запись считается оформленной после успешного подтверждения в приложении и/или системе записи центра.

Если выбранное время стало недоступно до завершения записи, пользователю будет предложено выбрать другое время.

## 3. Отмена

Пользователь может отменить запись в приложении, если до времени приёма осталось не менее 48 часов.

Если до приёма осталось менее 48 часов, отмена через приложение может быть недоступна. В таком случае пользователь может связаться с центром через чат или по телефону +7 980 395 07 99; +7 985 059 27 77.

## 4. Перенос

Перенос записи осуществляется через повторный выбор доступного времени либо через обращение в чат/по телефону.

## 5. Оплата

Оплата и предоплата в приложении не предусмотрены. Приложение не хранит банковские карты и не обрабатывает платёжные данные.

## 6. Уведомления

Пользователь может получать сервисные уведомления о записи, изменении статуса записи, напоминаниях и ответах в чате.

## 7. Внешние сервисы

Расписание и запись могут обрабатываться через YCLIENTS или иной подключённый сервис записи. При временной недоступности внешнего сервиса запись может быть недоступна.


## 8. Несовершеннолетние клиенты

Запись несовершеннолетнего клиента возможна через родителя или законного представителя. Родитель или законный представитель несёт ответственность за корректность переданных данных и сопровождение несовершеннолетнего в случаях, когда это требуется.
