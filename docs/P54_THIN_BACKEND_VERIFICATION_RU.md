# P54 — проверка схемы YCLIENTS + Telegram + тонкий backend

Проверенная цель: приложение остаётся полноценным приложением, а рабочие данные уходят во внешние системы.

## Итоговая схема

- Мобильное приложение сохраняет текущий интерфейс: главная, услуги, запись, мои записи, чат, профиль, документы.
- Backend остаётся на сервере как тонкий безопасный прокси.
- YCLIENTS является основным источником услуг, специалистов, дат, времени, создания записи, списка записей и отмены.
- Telegram является основным каналом чата и архивом фото/видео для администратора.
- Маленькая база нужна только для технических данных: сессии, согласия, связки клиент ↔ YCLIENTS/Telegram, индексы сообщений и статусы.

## Что было дополнительно исправлено после проверки P53

1. Услуги теперь могут загружаться из `/yclients/services`, а не только из локального контента приложения.
2. Экран приложения сохраняет красивый интерфейс, но при наличии YCLIENTS-данных показывает услуги от YCLIENTS.
3. Создание записи больше не создаёт фальшивую локальную запись на телефоне, если backend/YCLIENTS недоступен. Клиент увидит ошибку и запись не будет считаться созданной.
4. Обновление профиля теперь дополнительно пытается синхронизировать имя/фамилию клиента в YCLIENTS через thin backend.
5. Thin mode проверен через `/health` и `/yclients/status`.

## Важное ограничение

Для полноценного восстановления старой истории чата в приложении Telegram сам по себе недостаточен: Bot API не является базой истории для мобильного клиента. Поэтому маленькая база хранит технический индекс и текстовые сообщения, а фото/видео отправляются и архивируются в Telegram. Это сохраняет работу чата внутри приложения без тяжёлого медиа-хранилища.

## Что надо заполнить перед реальным запуском

- реальные ключи YCLIENTS / Altegio;
- реальные ID услуг и специалистов в `YCLIENTS_SERVICE_ID_MAP` и `YCLIENTS_STAFF_ID_MAP`;
- реальные Telegram bot token и group/forum ID;
- SMS.ru ключ;
- production `DATABASE_URL` для маленькой PostgreSQL базы;
- production HTTPS API URL;
- юридические URL на документы.
