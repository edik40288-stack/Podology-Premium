# Store compliance report — Apple / Google

## Назначение приложения

PODOLOG KUTSYTOI — клиентское приложение для записи, просмотра услуг, управления визитами и приватной коммуникации с центром ухода. Приложение не ставит диагнозы, не назначает лечение и не заменяет медицинскую консультацию.

## Данные пользователя

Приложение обрабатывает:

- имя и фамилию;
- телефон;
- записи/визиты;
- сообщения чата;
- фото/видео, которые пользователь сам выбирает из галереи;
- настройки уведомлений.

Не используется:

- реклама;
- трекинг между приложениями/сайтами;
- геолокация;
- контакты;
- микрофон/камера в текущем UI;
- продажа данных третьим лицам.

## Permissions

Android:

- INTERNET — связь с backend;
- READ_MEDIA_IMAGES / READ_MEDIA_VIDEO / READ_MEDIA_VISUAL_USER_SELECTED — выбор фото/видео из галереи для приватного чата.

iOS:

- NSPhotoLibraryUsageDescription — выбор фото/видео из галереи.

## Review access

Для магазинов нужен тестовый пользователь или включённый review/test mode на backend. Backend должен быть доступен во время проверки.

## User-generated content

Чат является приватным каналом клиент ↔ центр, не публичной социальной лентой. Все вложения сохраняются как технические сообщения и доставляются в рабочий канал центра.

## Account deletion

В профиле есть кнопка “Удалить аккаунт и данные”. Backend удаляет профиль, чат, локальные booking indexes и создаёт запрос на удаление/обработку в YCLIENTS при настроенном endpoint.
