# Клиентский чат через Telegram-группу с темами

Клиент пишет в приложении. Backend отправляет сообщение через чат-бота в Telegram-группу. Для нового клиента создаётся отдельная тема.

Сестра отвечает прямо в теме клиента. Backend получает ответ и добавляет его в чат приложения.

## Нужные переменные

```env
TELEGRAM_ENABLE_NOTIFICATIONS=true
TELEGRAM_CHAT_BRIDGE_ENABLE=true
TELEGRAM_CHAT_BOT_TOKEN=токен_чат_бота
TELEGRAM_CHAT_GROUP_ID=-100xxxxxxxxxx
TELEGRAM_CHAT_TOPICS_ENABLED=true
```

## Типовая проверка

1. Запусти проект.
2. В приложении отправь сообщение в чат.
3. В Telegram-группе появится тема клиента.
4. Ответь внутри темы.
5. Ответ появится в приложении.

## Режим для обычного администратора с V17

Telegram не должен использоваться как технический лог. В рабочую группу уходят только сообщения клиентов и важные действия по записи.

Правильная структура:

- одна тема = один клиент;
- название темы: `👤 Имя Фамилия · телефон`;
- администратор отвечает обычным сообщением прямо в теме клиента;
- синхронизация YCLIENTS, изменение услуг и специалистов проходят тихо.

Рекомендуемые настройки:

```env
TELEGRAM_CHAT_TOPICS_ENABLED=true
TELEGRAM_CHAT_REQUIRE_TOPICS=true
TELEGRAM_SYSTEM_EVENTS_TO_TELEGRAM=false
YCLIENTS_CATALOG_EVENTS_TO_TELEGRAM=false
```
