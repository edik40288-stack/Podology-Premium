# Карта данных для Privacy Policy / Data Safety

Приложение может обрабатывать:

- имя;
- фамилию;
- телефон;
- данные записи: услуга, специалист, дата, время;
- сообщения чата;
- фото/видео, если клиент отправляет их в чат;
- настройки уведомлений;
- технические данные запросов к backend.

Данные передаются:

- backend приложения;
- YCLIENTS/Altegio для создания записи;
- Telegram bot/group для уведомлений администратора и обработки чата;
- SMS.ru для отправки SMS-кода входа.

В приложении есть удаление аккаунта в профиле.
