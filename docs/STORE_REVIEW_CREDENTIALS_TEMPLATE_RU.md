# Шаблон данных для ревью Google Play / App Store

Перед отправкой в магазины укажи тестовый доступ в notes/review instructions.

```text
Для проверки приложения используйте тестовый вход:
Имя: <TEST_MODE_FIRST_NAME>
Фамилия: <TEST_MODE_LAST_NAME>
Телефон: <TEST_MODE_PHONE>

При вводе этих данных приложение автоматически откроет тестовый режим без отправки SMS. Тестовый режим показывает рабочие экраны записи, чата, профиля и контента без реальной записи клиента.

Privacy Policy: <PRIVACY_POLICY_URL>
Support: <SUPPORT_EMAIL>
```

Важно: эти значения должны совпадать с `.env` backend.
