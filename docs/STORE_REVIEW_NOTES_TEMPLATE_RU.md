# Review notes template — вставить в App Store Connect / Play Console

## Описание доступа

Приложение требует вход по номеру телефона. Для проверки используйте тестовый доступ, указанный ниже, или включённый backend test mode.

Имя: <TEST_MODE_FIRST_NAME>
Фамилия: <TEST_MODE_LAST_NAME>
Телефон: <TEST_MODE_PHONE>
Код: не требуется, если test mode включён; иначе будет отправлен SMS-код.

## Что проверить

1. Вход по телефону.
2. Просмотр услуг и специалистов.
3. Выбор даты/времени записи.
4. Создание тестовой записи через YCLIENTS staging/live test data.
5. Чат с центром.
6. Отправка фото/видео из галереи.
7. Удаление аккаунта в профиле.

## Важное пояснение

Приложение предназначено для записи и коммуникации с центром ухода. Оно не оказывает медицинскую диагностику, не назначает лечение и не является сервисом экстренной помощи.
