# V17 — Telegram для простого администратора

Цель: Telegram должен выглядеть как обычный понятный чат, а не как технический лог.

## Что изменено

| Было | Стало |
|---|---|
| При запуске/синхронизации могли приходить сообщения про добавленные услуги/специалистов | Синхронизация YCLIENTS проходит тихо. Услуги, специалисты, цены и расписание не спамят в Telegram |
| В общий чат/General могли попадать служебные уведомления | Системные уведомления выключены по умолчанию: `TELEGRAM_SYSTEM_EVENTS_TO_TELEGRAM=false` |
| Тема могла называться непонятно | Формат темы клиента: `👤 Имя Фамилия · +79990000000` |
| Сообщение было техническим: ID чата, тема, служебный заголовок | Сообщение простое: кто клиент, телефон, текст/фото/видео, и инструкция ответить в этой теме |
| Если админ писал не в теме клиента, бот мог отвечать лишним сообщением | Бот молчит. Подсказка только по команде `/help` |
| Запись/отмена/опоздание могли лететь как общий системный лог | Теперь важные события идут в тему конкретного клиента |

## Что теперь приходит в Telegram

Приходит только полезное для администратора:

- новое сообщение клиента;
- фото/видео клиента;
- новая запись;
- отмена записи;
- сообщение “я опаздываю”.

Не приходит:

- добавлена услуга;
- добавлен специалист;
- изменилась цена;
- обновился каталог YCLIENTS;
- backend стартовал;
- технические sync-события.

## Важные настройки

```env
TELEGRAM_ENABLE_NOTIFICATIONS=true
TELEGRAM_CHAT_BRIDGE_ENABLE=true
TELEGRAM_CHAT_TOPICS_ENABLED=true
TELEGRAM_CHAT_REQUIRE_TOPICS=true
TELEGRAM_SYSTEM_EVENTS_TO_TELEGRAM=false
YCLIENTS_IMPORTANT_EVENTS_TO_TELEGRAM=true
YCLIENTS_CATALOG_EVENTS_TO_TELEGRAM=false
```

## Как должен работать администратор

1. Открывает Telegram-группу `PODOLOG KUTSYTOI — чаты клиентов`.
2. Видит темы клиентов слева.
3. Заходит в тему клиента.
4. Читает сообщение/запись/опоздание.
5. Отвечает обычным сообщением в этой же теме.
6. Клиент видит ответ в приложении.
